我建议 M2-005《AI Mental Model》 不只是给 Rowboat 看，而是成为所有 AI 编程工具（Rowboat、Claude Code、Codex、Cursor 等）进入本项目时的第一份必读文档。

这个文档：

不是：

写代码。

而是：

告诉：

AI：

你应该如何思考。

例如：

第一句话：

你不是在开发一个监控平台。

第二句：

你是在构建企业 IT 系统的数字世界。

第三句：

Connector 不重要，Resource 才重要。

第四句：

Observation 是事实，不允许修改。

第五句：

所有 AI 推理都必须建立在 Fact→Evidence→Knowledge 链路上。

再例如：

错误思维：

我要采集 Redis。

正确思维：

我要发现一个新的 Resource。

例如：

错误思维：

CPU 高。

正确思维：

Order Service 的 Resource 出现了 CPU 异常 Observation。

例如：

错误思维：

Redis Down。

正确思维：

Redis Cluster Resource 生命周期进入 OFFLINE
