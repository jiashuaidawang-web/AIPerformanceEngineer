## 核心原则

### 必须装 Agent (✅)
> **所有运行 Java 业务代码的机器**

原因: 只有 JVM Agent 才能采集 GC/Heap/Thread/Method 级指标

### 可选装 Agent (⚠️)
> **中间件 / 数据库 / 基础设施**

原因: 这些组件有自带的监控接口 (INFO / JMX / API), Agent 通过网络采集即可, 不需要装在组件所在机器。

### 不装 Agent (❌)
> **纯基础设施 / 已有完善监控的组件**

原因: 通过 API / 日志 / Exporter 采集

## 关键: 中间件/基础设施接入流程

> **核心问题**: 中间件不装 Agent, 但 Agent 不知道去采集谁。必须把中间件实例"注册"到 Platform。

### 客户需要做什么

| 组件 | 开放什么 | 具体操作 | 难度 |
|------|---------|---------|------|
| **Redis** | INFO 命令 | 无 (默认开放) | ✅ 不改 |
| **MySQL** | 慢查询日志 | `SET GLOBAL slow_query_log = 1;` | ⭐ 加 2 行 |
| **Nginx** | stub_status | nginx.conf 加 3 行 | ⭐ 加 3 行 |
| **Kafka** | JMX 端口 | 启动参数加 `-Dcom.sun.management.jmxremote.port=9999` | ⭐⭐ |
| **RocketMQ** | mqadmin 工具 | 无 (自带) | ✅ 不改 |
| **ZooKeeper** | 四字命令 | 无 (内置) | ✅ 不改 |
| **Elasticsearch** | REST API | 无 (内置) | ✅ 不改 |
| **Kubernetes** | RBAC 授权 | 创建 ServiceAccount + ClusterRole | ⭐⭐ |

### 注册中间件的 3 种方式

#### 方式 1: 手动注册 (Dashboard 表单)

```
客户在 Dashboard → 资源管理 → 添加中间件:
  ├─ 类型: Redis
  ├─ 主机: 10.0.100.1
  ├─ 端口: 6379
  └─ 保存

→ Platform 创建 Resource (type=REDIS, host=10.0.100.1)
→ Agent 读取 Resource 表, 开始采集
```

#### 方式 2: Agent 自动发现 (推荐)

```yaml
# Agent 配置 (config.yaml)
discovery:
  redis:
    enabled: true
    scan_ports: [6379, 6380, 16379]
    scan_cidr: "10.0.0.0/8"      # 扫描内网网段
  mysql:
    enabled: true
    scan_ports: [3306, 33060]
  nginx:
    enabled: true
    scan_ports: [80, 443, 8080, 9091]
  kafka:
    enabled: true
    scan_ports: [9092, 9093]
  zookeeper:
    enabled: true
    scan_ports: [2181, 2182]

# Agent 行为
# 1. 启动时扫描 scan_cidr 网段的 scan_ports
# 2. 发现存活实例 (如 Redis 响应 INFO)
# 3. 上报 Platform → 自动创建 Resource
# 4. 按 Resource 类型选择采集方式
```

#### 方式 3: 对接客户 CMDB (企业级)

```
客户 CMDB (已有所有服务器信息)
    ↓ API 同步
Platform Resource 表
    ↓ Agent 读取
开始采集
```

**CMDB 同步接口示例**:
```json
POST /api/v1/resources/sync
[
  {"name": "订单Redis", "type": "REDIS", "host": "10.0.100.1", "port": 6379},
  {"name": "订单MySQL", "type": "DATABASE", "host": "10.0.102.1", "port": 3306}
]
```

### 2. Redis — 不装 Agent, 通过网络采集

```
┌─ Redis Server (192.168.10.0)
│
└─ Redis Cluster (不装任何东西)
```
