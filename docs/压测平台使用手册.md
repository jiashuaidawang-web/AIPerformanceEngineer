## 常见问题

**Q: Timeline 返回 0 数据点?**  
A: 检查 timestamp 范围是否匹配 Observation 的存储时间。ClickHouse DateTime64(3) 存储的是秒级时间戳, 查询范围需要对应。

**Q: Evidence 未自动生成?**  
A: Evidence 引擎基于规则: 需有 ≥3 个连续超阈值 (默认 80%) 数据点才会触发。

**Q: Knowledge successRate 不更新?**  
A: 需要完成 Execution (调用 /complete) 并传入 afterSnapshot, 系统自动计算提升幅度。

**Q: 压测响应慢?**  
A: 4G 内存同时跑 8+1 容器属于极限压测, 建议生产环境 ≥16G。
