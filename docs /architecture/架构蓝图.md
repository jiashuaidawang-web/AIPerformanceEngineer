我还有一个建议（我认为这个比 MDP 还重要）

从现在开始，所有 AI（包括 Rowboat）每次启动开发前，第一步不是扫描代码，而是先读取这两份文档：

1. 00-Master-Development-Plan.md
2. 01-Blueprint-Template.md

然后严格执行以下流程：
读取 MDP
↓
确定当前 WP（例如 WP004）
↓
读取对应 Blueprint（WP004）
↓
生成开发计划
↓
物理创建文件
↓
编译
↓
自测
↓
更新 MDP 状态（Not Started → In Progress → Done）
↓
Git Commit

这样，MDP 就不仅是一份文档，而是整个项目的"调度器（Scheduler）"。任何 AI Coding Agent 都不需要你再告诉它"下一步做什么"，
它只要遵守 MDP 和对应的 Blueprint，就能持续、自主、按计划完成整个项目。
