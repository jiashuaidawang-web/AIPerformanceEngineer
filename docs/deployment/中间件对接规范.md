## 1. 对接规范总览

### 1.1 组件对接方式矩阵

| 中间件 | 对接方式 | 需要装 Agent? | 需要重启? | 客户改动 |
|--------|---------|--------------|----------|---------|
| **Redis** | Agent 网络采集 | ❌ | ❌ 不需要 | 开放网络连接 |
| **MySQL** | Agent 网络采集 | ❌ | ❌ 不需要 | 授权 + 开慢查询日志 |
| **Nginx** | Agent 探测 stub_status | ❌ | ❌ 不需要 | 加 3 行配置 + reload |
| **Java 应用** | Agent 本机采集 | ✅ 必须 | ❌ 不需要 | 无 |
| **ClickHouse** | 平台自带 | ❌ | — | — |
| **Kubernetes** | RBAC 授权 | ✅ DaemonSet | ❌ 不需要 | 创建 ServiceAccount |

### 1.2 通用前提条件

| 条件 | 说明 |
|------|------|
| 网络 | Agent → Platform 出向 443 开放 |
| JDK | 1.8+ (包含 jcmd, jstat, jmap) |
| OS | Linux (CentOS 7+, Ubuntu 20.04+) 或 macOS |
| 权限 | Agent 与业务 JVM 同用户或 root |

## 2. Agent 部署对接

### 2.1 部署方式选择

| 场景 | 部署方式 | 命令 |
|------|---------|------|
| 传统 VM/ECS | systemd Daemon | `curl -fsSL https://install.aipe.io/install.sh \| bash` |
| Kubernetes | DaemonSet | `kubectl apply -f https://install.aipe.io/daemonset.yaml` |
| Docker 容器 | Sidecar | 在 Deployment 添加容器 |
| 本地开发 | 直接运行 | `java -jar aipe-agent.jar` |

### 2.2 Agent 配置文件 (config.yaml)

**文件位置**: `/opt/aipe/agent/config.yaml` (VM) 或 ConfigMap (K8s)

```yaml
agent:
  agentId: "agent-001"              # 唯一标识，每台机器一个
  serverId: "server-001"            # 服务器分组
  environment: "prod"               # 环境标识: prod/staging/test
  backendUrl: "http://localhost:8081"  # Platform Backend 地址
  schedulerPoolSize: 4              # 调度线程数
  sendTimeoutMs: 5000               # 发送超时

  connectors:
    # ====== JVM (必须启用) ======
    - type: JVM
      enabled: true
      intervalMs: 30000             # 采集间隔 30 秒
      properties:
        jvmType: hotspot            # JVM 类型: hotspot/openj9

    # ====== Linux 系统指标 ======
    - type: LINUX
      enabled: true
      intervalMs: 30000
      properties:
        procPath: /proc              # /proc 路径 (Linux)

    # ====== Redis (按需启用) ======
    - type: REDIS
      enabled: true
      intervalMs: 30000
      properties:
        host: "124.223.220.245"     # Redis IP
        port: "6379"                # Redis 端口
        password: "pamirs@123"      # Redis 密码 (如果有)

    # ====== MySQL (按需启用) ======
    - type: MYSQL
      enabled: true
      intervalMs: 30000
      properties:
        host: "124.223.220.245"     # MySQL IP
        port: "3306"                # MySQL 端口
        user: "root"                # 授权用户
        password: "astock_root"     # 密码
        database: "aipe_metadata"    # 默认数据库
```

## 3. Redis 对接规范

### 3.1 对接方式

| 方式 | 说明 | 推荐度 | 重启? |
|------|------|--------|-------|
| **Agent 网络采集** | Agent 连接 Redis 执行 INFO 命令 | ⭐⭐⭐⭐⭐ | ❌ 不需要 |
| Agent 自动发现 | Agent 扫描内网 Redis 端口 (6379) | ⭐⭐⭐⭐ | ❌ 不需要 |

### 3.2 客户需要做的事

#### 方式 A: Agent 直连 (推荐，零改动)

**不需要重启 Redis**，只需要:

| # | 操作 | 命令/说明 | 必须? |
|---|------|----------|-------|
| 1 | 开放网络连接 | Agent → Redis:6379 端口可达 | ✅ 必须 |
| 2 | 确认密码 | 如果有密码，写入 Agent 配置 | ⚠️ 如果有密码 |
| 3 | 验证连接 | `redis-cli -h <host> -a <password> ping` | ✅ 验证 |

#### 方式 B: Agent 自动发现

```yaml
- type: REDIS
  enabled: true
  properties:
    scanCidr: "10.0.0.0/8"           # 扫描的内网网段
    scanPorts: [6379, 6380, 16379]    # Redis 常见端口
    password: "pamirs@123"            # 如果所有 Redis 密码相同
```

## 4. MySQL 对接规范

### 4.1 对接方式

| 方式 | 说明 | 推荐度 | 重启? |
|------|------|--------|-------|
| **Agent 网络采集** | Agent 连接 MySQL 执行 SHOW STATUS | ⭐⭐⭐⭐⭐ | ❌ 不需要 |
| 慢查询日志拉取 | Agent 读取慢查询日志文件 | ⭐⭐ | ⚠️ 开慢查询需重启或动态设置 |
| MySQL Exporter | 对接已有 Prometheus MySQL Exporter | ⭐⭐⭐ | ❌ |

### 4.2 客户需要做的事

#### ✅ Step 1: 创建授权用户 (推荐)

**不需要重启 MySQL**，只需执行 SQL:

```sql
-- 创建专用监控用户
CREATE USER 'aipe_monitor'@'%' IDENTIFIED BY 'StrongPassword123!';

-- 授权只读权限
GRANT PROCESS, REPLICATION CLIENT ON *.* TO 'aipe_monitor'@'%';
GRANT SELECT ON performance_schema.* TO 'aipe_monitor'@'%';
GRANT SELECT ON mysql.slow_log TO 'aipe_monitor'@'%';

FLUSH PRIVILEGES;
```

#### ✅ Step 2: 开启慢查询日志 (可选)

**方式 A: 动态设置 (无需重启，但重启后失效)**:

```sql
SET GLOBAL slow_query_log = 'ON';
SET GLOBAL slow_query_log_file = '/var/log/mysql/slow.log';
SET GLOBAL long_query_time = 1;
```

**方式 B: 永久配置 (需要重启 MySQL)**:

```ini
# my.cnf
[mysqld]
slow_query_log = 1
slow_query_log_file = /var/log/mysql/slow.log
long_query_time = 1
log_queries_not_using_indexes = 1
```

#### ✅ Step 3: Agent 配置

```yaml
- type: MYSQL
  enabled: true
  intervalMs: 30000
  properties:
    host: "124.223.220.245"
    port: "3306"
    user: "aipe_monitor"           # 推荐专用用户
    password: "StrongPassword123!"
    database: "aipe_metadata"
```

## 5. Nginx 对接规范

### 5.1 对接方式

| 方式 | 说明 | 推荐度 | 重启? |
|------|------|--------|-------|
| **stub_status** | Nginx 开启状态页，Agent 采集 | ⭐⭐⭐⭐⭐ | ❌ 只需 reload |
| 日志分析 | Agent 分析 access.log | ⭐⭐⭐ | ❌ |

### 5.2 客户需要做的事

#### ✅ 开启 stub_status (加 3 行配置，reload 即可)

在 Nginx 配置中添加:

```nginx
server {
    listen 9091;               # 专用状态端口
    server_name localhost;

    location /nginx_status {
        stub_status on;         # 开启状态页
        allow 127.0.0.1;        # 只允许本地
        allow 10.0.0.0/8;       # 允许内网 Agent
        deny all;
    }
}
```

**重载 Nginx (不中断服务)**:
```bash
nginx -s reload
```

| nginx.connections.writing | 写入连接数 |
| nginx.connections.waiting | 等待连接数 |
| nginx.requests.total | 总请求数 |
| nginx.requests.per_second | 实时 QPS |

## 6. Java 应用 (JVM) 对接规范

### 6.1 对接方式

Java 应用通过 Agent **本机采集**，不需要修改业务代码或重启应用。

| 方式 | 说明 | 推荐度 | 重启? |
|------|------|--------|-------|
| **jcmd/jstat 附加** | Agent 通过 JDK 工具附加到运行中的 JVM | ⭐⭐⭐⭐⭐ | ❌ 不需要 |
| JMX Remote | 开启 JMX 远程连接 | ⭐⭐⭐ | ❌ 不需要 (动态开启) |
| javaagent | 启动时加 -javaagent 参数 | ⭐⭐ | ✅ 需要重启 |

### 6.2 客户需要做的事

#### 方式 A: 零侵入 (推荐)

**不需要修改业务代码、不需要重启应用**，只需要:

| # | 操作 | 说明 | 必须? |
|---|------|------|-------|
| 1 | 安装 Agent | 在业务服务器上装 Agent | ✅ |
| 2 | 同用户运行 | Agent 与业务 JVM 同用户 (或 root) | ✅ |
| 3 | JDK 1.8+ | 确保 JDK 包含 jcmd/jstat | ✅ |
| 4 | Agent 配置 JVM connector | `enabled: true` | ✅ |

#### 方式 B: JMX Remote (如需更详细指标)

**动态开启 (无需重启)**:

```bash
jcmd <pid> ManagementAgent.start jmxremote.port=9999 jmxremote.authenticate=false jmxremote.ssl=false
```

**永久配置 (需要重启)**:

```bash
java -Dcom.sun.management.jmxremote \
     -Dcom.sun.management.jmxremote.port=9999 \
     -Dcom.sun.management.jmxremote.authenticate=false \
     -Dcom.sun.management.jmxremote.ssl=false \
     -jar your-app.jar
```

## 7. ClickHouse 对接规范

### 7.1 对接方式

ClickHouse 是 **平台自带** (SaaS 模式)，客户不需要部署。

| 部署模式 | ClickHouse 位置 | 客户需要做什么 |
|---------|----------------|--------------|
| SaaS (推荐) | 我们的云 | 无 |
| 私有化部署 | 客户指定 | 提供连接信息 |

### 7.2 私有化部署时客户需要提供

| 配置项 | 说明 | 示例 |
|--------|------|------|
| host | ClickHouse IP | 124.223.220.245 |
| port | HTTP 端口 | 8123 |
| username | 用户名 | default |
| password | 密码 | pamirs@123 |
| database | 数据库名 | metric_observation |

### 7.3 ClickHouse 表结构

```sql
CREATE TABLE IF NOT EXISTS observation_fact (
    id UUID DEFAULT generateUUIDv4(),
    timestamp DateTime DEFAULT now(),
    resource_id String,
    resource_type String DEFAULT 'HOST',
    metric_name String,
    metric_value Float64,
    labels String DEFAULT ''
) ENGINE = MergeTree()
PARTITION BY toYYYYMM(timestamp)
ORDER BY (resource_id, metric_name, timestamp)
TTL timestamp + INTERVAL 365 DAY;
```

## 8. Kubernetes 对接规范

### 8.1 部署方式

| 方式 | 说明 | 推荐度 |
|------|------|--------|
| **DaemonSet** | 每台节点一个 Agent | ⭐⭐⭐⭐⭐ |
| Sidecar | 每个业务 Pod 旁加 Agent | ⭐⭐⭐ |
| Collector Agent | 独立采集器 | ⭐⭐⭐⭐ |

### 8.2 DaemonSet 部署

```yaml
apiVersion: v1
kind: Namespace
metadata:
  name: aipe-system
---
apiVersion: v1
kind: ServiceAccount
metadata:
  name: aipe-agent
  namespace: aipe-system
---
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRole
metadata:
  name: aipe-agent
rules:
- apiGroups: [""]
  resources: ["nodes", "pods", "services"]
  verbs: ["get", "list", "watch"]
---
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRoleBinding
metadata:
  name: aipe-agent
roleRef:
  apiGroup: rbac.authorization.k8s.io
  kind: ClusterRole
  name: aipe-agent
subjects:
- kind: ServiceAccount
  name: aipe-agent
  namespace: aipe-system
---
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: aipe-agent
  namespace: aipe-system
spec:
  selector:
    matchLabels:
      app: aipe-agent
  template:
    metadata:
      labels:
        app: aipe-agent
    spec:
      serviceAccountName: aipe-agent
      hostNetwork: true
      hostPID: true
      containers:
      - name: aipe-agent
        image: aipe/agent:latest
        resources:
          limits:
            cpu: "500m"
            memory: "256Mi"
          requests:
            cpu: "100m"
            memory: "128Mi"
        env:
        - name: AIPE_AGENT_ID
          valueFrom:
            fieldRef:
              fieldPath: spec.nodeName
        - name: AIPE_PLATFORM_URL
          value: "https://platform.aipe.io"
        - name: AIPE_API_KEY
          valueFrom:
            secretKeyRef:
              name: aipe-credentials
              key: api-key
        volumeMounts:
        - name: proc
          mountPath: /host/proc
          readOnly: true
      volumes:
      - name: proc
        hostPath:
          path: /proc
```

### 8.3 K8s 客户需要做的事

| # | 操作 | 命令 | 必须? |
|---|------|------|-------|
| 1 | 创建 Namespace | `kubectl create ns aipe-system` | ✅ |
| 2 | 创建 RBAC | `kubectl apply -f rbac.yaml` | ✅ |
| 3 | 创建 Secret | `kubectl create secret generic aipe-credentials --from-literal-api-key=xxx -n aipe-system` | ✅ |
| 4 | 部署 DaemonSet | `kubectl apply -f daemonset.yaml` | ✅ |
| 5 | 验证 | `kubectl get pods -n aipe-system` | ✅ |

#!/bin/bash
# install_aipe_agent.sh — AI Performance Agent 一键安装

set -e

INSTALL_DIR="/opt/aipe/agent"
PLATFORM_URL="${1:-https://platform.aipe.io}"
API_KEY="${2:-YOUR_API_KEY}"

echo "=== AI Performance Agent 安装 ==="
echo "平台: ${PLATFORM_URL}"

# 1. 创建目录
mkdir -p ${INSTALL_DIR}

# 2. 下载 Agent
curl -fsSL ${PLATFORM_URL}/download/agent -o ${INSTALL_DIR}/aipe-agent.jar

# 3. 创建配置
cat > ${INSTALL_DIR}/config.yaml << EOF
agent:
  agentId: "agent-$(hostname)"
  serverId: "$(hostname)"
  environment: "prod"
  backendUrl: "${PLATFORM_URL}"
  schedulerPoolSize: 4
  sendTimeoutMs: 5000
  connectors:
    - type: JVM
      enabled: true
      intervalMs: 30000
      properties:
        jvmType: hotspot
    - type: LINUX
      enabled: true
      intervalMs: 30000
      properties:
        procPath: /proc
EOF

# 4. 创建 systemd 服务
cat > /etc/systemd/system/aipe-agent.service << EOF
[Unit]
Description=AI Performance Agent
