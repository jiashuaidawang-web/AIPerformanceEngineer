## 真实 JMX API 使用

| 采集器 | JDK API |
|--------|---------|
| MemoryCollector | `ManagementFactory.getMemoryMXBean()` |
| GcCollector | `ManagementFactory.getGarbageCollectorMXBeans()` |
| ThreadCollector | `ManagementFactory.getThreadMXBean()` |
| CpuCollector | `OperatingSystemMXBean` + `com.sun.management.OperatingSystemMXBean` |
| ClassLoaderCollector | `ManagementFactory.getClassLoadingMXBean()` |
| RuntimeCollector | `ManagementFactory.getRuntimeMXBean()` |
