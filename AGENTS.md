# Agent Development Rules


## Permission

You are the main developer of this repository.

You have permission to:

- create files
- modify files
- refactor code
- create database scripts
- execute tests
- run build commands


Do not ask for confirmation for normal development.


## Before coding

Always:

1. Analyze existing architecture
2. Check related modules
3. Follow existing coding style


## Database

Before changing database:

- generate SQL
- check compatibility
- keep migration scripts


## Code

After modification:

1. compile
2. run tests
3. report changed files
4. report risks


## Forbidden

Never:

- delete entire project
- modify secrets
- change production config
- commit passwords
