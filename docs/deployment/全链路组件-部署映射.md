## 核心原则

### 必须装 Agent (✅)
> **所有运行 Java 业务代码的机器**

原因: 只有 JVM Agent 才能采集 GC/Heap/Thread/Method 级指标

### 可选装 Agent (⚠️)
> **中间件 / 数据库 / 基础设施**

原因: 这些组件有自带的监控接口 (INFO / JMX / API), Agent 通过网络采集即可, 不需要装在组件所在机器。

### 不装 Agent (❌)
> **纯基础设施 / 已有完善监控的组件**

原因: 通过 API / 日志 / Exporter 采集

## 详细部署策略

### 1. 业务服务 (Java 微服务) — 必须装

```
┌─ App Server (192.168.1.0)
│
├─ java - jar order-svc.jar          ← 客户业务 (不改)
│
└─ aipe-agent (我们的 Daemon)        ← 每台机器装 1 个
   ├─ 通过 Attach API 挂载到业务 JVM
   ├─ 采集: GC / Heap / Thread / TPS / RT
   └─ 上报: HTTPS → Platform
```

**部署方式**: systemd Daemon (每台机器)

```bash
# 一键安装
curl -fsSL https://install.aipe.io/install.sh | bash -s \
  --api-key=YOUR_KEY --cluster=order-cluster
```

### 2. Redis — 不装 Agent, 通过网络采集

```
┌─ Redis Server (192.168.10.0)
│
└─ Redis Cluster (不装任何东西)
   │
   └─ aipe-agent (在 App Server 上) 通过网络采集:
      ├─ redis-cli INFO → 内存/连接/命中
      ├─ redis-cli SLOWLOG → 慢查询
      └─ redis-cli CLUSTER INFO → 集群状态
```

**为什么 Redis 不装 Agent?**
- Redis 是 C 语言, 无法用 JVM Agent
- Redis 自带 INFO 命令, 指标足够
- Agent 在 App Server 上通过网络采集, 无侵入

### 3. MySQL — 不装 Agent, 通过慢查询日志 + exporter

```
┌─ MySQL Server (192.168.10.1)
│
└─ MySQL (不装任何东西)
   │
   ├─ 慢查询日志 (客户开启: slow_query_log=1)
   │
   └─ aipe-agent (在 App Server 上) 采集:
      ├─ 慢查询日志文件 (通过 syslog 或文件采集)
      ├─ SHOW PROCESSLIST (可选)
      └─ performance_schema (可选)
```

### 4. RocketMQ/Kafka — 不装 Agent, 通过控制台 API

```
┌─ RocketMQ (192.168.20.0)
│
└─ RocketMQ Broker (不装)
   │
   └─ aipe-agent 采集:
      ├─ mqadmin 命令行工具
      └─ 控制台 API (如有)
```

### 5. Nginx — 不装 Agent, 通过 stub_status

```
┌─ Nginx (192.168.0.1)
│
└─ nginx.conf (客户加 3 行)
   server {
       listen 9091;
       location /nginx_status {
           stub_status on;       ← 客户加这行
           allow 127.0.0.1;
           deny all;
       }
   }
   
   └─ aipe-agent 采集: curl http://localhost:9091/nginx_status
```

### 6. Kubernetes (如有) — DaemonSet 部署

```yaml
# 如果客户用 K8s, Agent 以 DaemonSet 部署
apiVersion: apps/v1
kind: DaemonSet
metadata:
  name: aipe-agent
  namespace: aipe-system
spec:
  selector:
    matchLabels:
      app: aipe-agent
  template:
    spec:
      hostPID: true        # 采集主机进程
      hostNetwork: true    # 采集主机网络
      containers:
        - name: agent
          image: aipe/agent:latest
          securityContext:
            privileged: true
```

## 一句话总结

| 组件 | 装什么 | 怎么采 |
|------|-------|--------|
| **Java 业务服务** | ✅ Agent (必须) | JVM Attach |

| **Nginx** | ❌ 不装 | stub_status |
| **基础设施** | ❌ 不装 | 系统指标 / 日志 |

**核心**: Agent 只装在跑 Java 业务代码的机器上, 其他组件通过网络无侵入采集。
