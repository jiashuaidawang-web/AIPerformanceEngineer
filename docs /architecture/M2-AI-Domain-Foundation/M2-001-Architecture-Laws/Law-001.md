Law-001
Resource Ownership Principle（资源统一归属原则）
Purpose

企业中的所有对象（Everything）都必须统一抽象为 Resource。

整个 AI 世界只有一种对象：

Resource

Why

传统平台：

Host

Redis

MySQL

Kafka

JVM

Pod

都是不同的数据模型。

AI 无法统一理解。

因此：

统一抽象：

Everything Is Resource
Rule

任何 Connector：

禁止：

new Resource()

禁止：

save(Resource)

必须：

Connector

↓

ConnectorResourceMapper

↓

ResourceDiscoveryService

↓

ResourceRepository

统一创建。

Resource Ownership

唯一：

ResourceRepository

负责：

Create
Merge
Update
Lifecycle

任何其他模块禁止维护 Resource。

Summary

Everything Is Resource.
