## 常见问答

**Q: 客户需要部署几个 Agent?**  
A: 每台需要监控的 App Server 装 1 个。Nginx 机器不需要单独装, App Server 上的 Agent 会探测并采集 Nginx 指标。

**Q: Agent 挂了怎么办?**  
A: 该机器的观测数据会中断, 不影响其他机器。客户可通过 `systemctl restart aipe-agent` 恢复。

**Q: 我们能控制客户的应用吗?**  
A: 不能。Agent 只读, 不修改业务配置。Execution Service 也只是记录, 不主动执行操作 (除非客户授权)。

**Q: 数据出客户环境吗?**  
A: 指标数据会上报, 但可选择脱敏 (IP 哈希, 主机名替换)。Config 可设置数据不出域 (On-Prem 模式)。
